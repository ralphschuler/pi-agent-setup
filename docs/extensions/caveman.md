# Caveman

`extensions/caveman/` registers `/caveman`, a command for toggling terse caveman or wenyan-style assistant language.

## Modes

- `lite`
- `full`
- `ultra`
- `wenyan-lite`
- `wenyan`
- `wenyan-ultra`

## Usage

```text
/caveman lite
/caveman off
```

The extension changes assistant style, not tool behavior or repository state.
