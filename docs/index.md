# Custom Pi Agent Setup Wiki

This wiki documents the `pi-agent-setup` repository: a custom package for the pi coding agent with extensions, skills, prompts, themes, scripts, and tests.

## What is included

- **Extensions**: custom tools, slash commands, TUI widgets, workflow helpers, and safety features.
- **Skills**: reusable task workflows for reviews, debugging, processes, subagents, and project bootstrap work.
- **Prompts**: reusable prompt templates exposed as slash commands when prompt commands are enabled.
- **Themes**: custom pi TUI themes, including synthwave.
- **Scripts**: install, update, uninstall, check, and Docker validation helpers.
- **CI/CD**: repository checks plus this wiki deployment to GitHub Pages.
