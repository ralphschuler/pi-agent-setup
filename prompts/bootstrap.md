Bootstrap or improve this repository with a clarification-first workflow.

Steps:

1. Inspect the current structure, package metadata, scripts, tests, CI, docs, and existing changes.
2. Clarify scope, constraints, deletion/rename policy, dependency policy, and validation target before editing.
3. Produce a concise reviewable plan with risks and rollback notes.
4. After approval, implement repository hygiene, scripts, docs, tests, and validation in small steps.
5. Report changed files and commands run.

Do not modify files until the plan is approved.
